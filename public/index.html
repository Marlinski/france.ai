À propos de france.re

france.re est un service indépendant et non officiel, sans lien avec l'État français. Un assistant d'intelligence artificielle y recherche l'information dans les données publiques ouvertes : fiches pratiques de Service-Public.fr (DILA, Licence Ouverte), catalogue data.gouv.fr via son serveur MCP officiel, et d'autres API publiques via le serveur communautaire mcp-service-public.

L'IA peut se tromper : vérifiez toujours sur le site officiel indiqué en source avant d'agir. Ne partagez jamais de données sensibles (numéro fiscal, numéro de sécurité sociale, mots de passe). Pour une aide humaine : 3939 Allô Service Public ou un espace France Services.
